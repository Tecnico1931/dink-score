# Security policy

Dink Score is a small project run by volunteers. We take security reports seriously.

## Reporting a vulnerability

Please report privately. **Do not open a public issue, pull request or discussion for a security problem.**

- Use GitHub's private vulnerability reporting: <https://github.com/Tecnico1931/dink-score/security/advisories/new> (the repository's **Security** tab, then **Report a vulnerability**).
- Include what you found, where, and how to see it. Say whether real club data could be affected.

We aim to acknowledge a report within 5 working days and to tell you when it is fixed. Please give us a reasonable time to fix a problem before sharing details.

## Please do

- Test only with clubs and events you created yourself.
- Stop and tell us if you reach other people's data; do not copy, keep or share it.

## Please do not

- Run denial-of-service, spam or large automated guessing against the live site.
- Attempt social engineering of players or organizers.
- Call DUPR's systems through this app in ways its own terms do not allow.

## Scope

The app at <https://dinkscore.vercel.app> and the code in this repository. Problems in Vercel, Neon or DUPR themselves should go to those providers.

## Maintainers

Owner action: turn on **Private vulnerability reporting** in the repository's *Settings > Code security* so the link above works. This file cannot switch it on.

A machine-readable copy of this policy is served at `/.well-known/security.txt`.
